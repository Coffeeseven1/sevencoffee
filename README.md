# SEVEN Cafe & Games — V2

نسخه دوم منوی دیجیتال کافه سون با تم مشکی، قرمز و زرد.

## قابلیت‌ها
- صفحه اصلی با دو بخش منوی کافه و گیم‌ها
- دسته‌بندی کافه: نوشیدنی گرم، نوشیدنی سرد، دسر، غذا
- دسته‌بندی بازی: VIP، بیلیارد، PS5، PS4، Xbox، بردگیم
- دکمه جابه‌جایی مستقیم بین منوی کافه و گیم‌ها در صفحات دسته‌بندی و محصولات
- پنل مدیریت برای افزودن، ویرایش و حذف محصولات، قیمت و URL تصویر
- فیلد تعرفه برای ۱ تا ۵ ساعت برای هر آیتم گیم
- ذخیره اطلاعات در localStorage همین مرورگر
- خروجی و ورود اطلاعات JSON

## اجرا
`index.html` را باز کنید یا فایل‌ها را روی GitHub Pages / Cloudflare Pages منتشر کنید.

## توجه مهم
این پنل مدیریت فعلاً فقط اطلاعات را در مرورگر همان دستگاه ذخیره می‌کند؛ بنابراین اطلاعات بین گوشی مشتری‌ها یا مدیران همگام نمی‌شود و احراز هویت ندارد. برای پنل مدیریت واقعی و امن که همه دستگاه‌ها قیمت‌های یکسان ببینند، باید یک API/پایگاه داده و ورود مدیر اضافه شود.
